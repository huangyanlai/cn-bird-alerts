v1.0.45 (2026-10-12)
1. 全新「🗺️ 鸟种分布与热门鸟点」离线大数据模块：内置全国 34 个省/直辖市/自治区近 6 年（2020–2026）观鸟分布与热点离线引擎。
2. 🐦 鸟种分布与居留型分析：支持查询任意鸟种在全国、各省及市/区县的居留型（留鸟 / 夏候鸟 / 冬候鸟 / 迁徙过境 / 迷鸟或偶见）、6 年总报告数与总个体数、36 旬活跃度曲线、主要出现窗口期，以及该地区观测到该鸟种的高频热门鸟点排行。
3. 📍 热门鸟点排行与最佳造访期：支持按全国、省、市/区县及时间段（全年、指定月份或具体上/中/下旬）查看热门观鸟点 Top 50 排行，支持搜索鸟点并查看单鸟点 36 旬鸟种丰富度与观测活跃度曲线、推荐最佳造访期及代表性高频鸟种（点击鸟种可一键跳转查看其分布详情）。
4. 🧹 全国高频观鸟热点名称归一化：对全国 1,530 个高频观鸟点的 5,923 个同地异名/大门/子区域别名（如「南汇东滩」、「奥林匹克森林公园南园」、「乐活中堤」等）进行了系统性归一化合并，大幅提升热点统计准确度。

v1.0.30 (2026-10-12)
1. 自定义鸟种集合管理与剪贴板提取：在「设置」页新增「📋 自定义鸟种集合」卡片，支持创建与管理多个鸟种名录集合，可一键「从剪贴板提取」识别鸟种名称，或通过多选检索弹窗按中文名、拼音首字母、英文名、拉丁学名批量添加与复制鸟种。
2. 基于鸟种集合的包含 (INCLUDE) 与排除 (EXCLUDE) 提醒模式：创建或编辑提醒时，除基于个人已见鸟种（此地点已见 / 全国已见）外，新增「鸟种集合包含 (INCLUDE)」（仅当集合内的目标鸟种出现时提醒）与「鸟种集合排除 (EXCLUDE)」（当集合外的未记录鸟种出现时提醒）两种检测方式，并支持在提醒编辑弹窗内直接新建或编辑集合。
3. 鸟种汇总三段式时间分组：将原「近期出现（今天 / 昨天）」拆分为独立的「🔥 今天出现」与「🌤️ 昨天出现」两个分组，按「今天出现 -> 昨天出现 -> 更早记录（2天前及更早）」顺序依次展示，各分组内均支持未读优先排序。
4. 鸟种多名称与别名全链路匹配（如「环颈雉 / 雉鸡」、「理氏鹨 / 田鹨」等 194 种异名鸟类）：内置完整鸟种别名与备用拼音词典，支持在鸟种选择弹窗中通过任意中文名或拼音首字母（如 环颈雉 / 雉鸡 / hjz / zj）搜索、从剪贴板识别所有别名并统一为标准名，且在生成新鸟提醒、匹配个人已见鸟种基线、自定义鸟种集合（INCLUDE / EXCLUDE）及忽略鸟种时自动双向展开所有同义鸟名。

v1.0.23 (2026-10-11)
1. 鸟种卡片时间展示优化：鸟种汇总卡片优先展示「最近」观测时间段，并将「最早」精简为仅展示日期（最近：<时间段> 最早：<日期>），重点更突出、单行展示更紧凑。
2. 刷新后未读新记录优先排序：在「🔥 近期出现」与「📅 更早记录」各分组内，刷新后自动将有新增未读记录（NEW）的鸟种排在最前；浏览点开鸟种标为已读时保持当前列表顺序不变，避免列表跳动。
3. 鸟种汇总未读筛选：在「鸟种汇总」视图新增「仅看未读」筛选开关，开启后仅展示有新增未读记录的鸟种，且点击鸟种打开详情弹窗时仅展示未读观测记录。
4. 忽略鸟种界面精简：移除全局忽略鸟种与单提醒忽略鸟种配置中重复的文本输入框，统一通过「搜索 / 批量选择」按钮与可点击移除标签管理。

v1.0.18 (2026-10-11)

v1.0.16 (2026-10-10)
1. 智能未读排序与点击自动已读：查看鸟种详情或记录明细时，观测记录自动按「未读在前、已读在后，时间由新到旧」排序；点击鸟种查看详情时自动将该鸟种记录标记为已读。

v1.0.8 (2026-10-09)
1. 鸟讯 (bird_alert) 发布：原生 Android 目标新鸟发现与提醒应用，支持从中国观鸟记录中心 (`birdreport.cn`) 获取最新观鸟记录，在应用内直接展示关注区域的近期新鸟讯息。
2. 多提醒配置与双范围基线对比：支持配置一个或多个关注地点提醒（支持省/直辖市、州/市、区/县、观测点名称四级精细化地点过滤），每个提醒可独立选择已见鸟种对比范围——「此地点已见」或「全国已见」。
3. 鸟种汇总与记录明细双视图：提供「鸟种汇总」（区分「近期出现（今天/昨天）」与「更早记录」，展示观测时间及前 3 大热门观测点）与「记录明细」（支持按未读新记录筛选与一键标为已读）。
4. 多级本地缓存与基线名录查看：支持每日鸟种缓存、观测记录缓存与用户已见鸟种基线缓存管理，可在设置页直接查看与检索个人已见鸟种名录。
